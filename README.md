# 🚗 OAC — Car Wash / Service Web App

---

## 🚀 Description

OAC est une application web dédiée à la gestion et à la présentation d’un service de lavage automobile.
Le projet propose une interface moderne permettant de présenter les services, les prestations et les informations liées à l’activité.

---

## 🎯 Objectif du projet

* Créer une interface web simple et intuitive
* Présenter un service de car wash de manière professionnelle
* Mettre en avant les prestations proposées
* Développer un site statique responsive

---

## 🛠️ Technologies utilisées

* React
* SASS
* JavaScript

---

## 📂 Fonctionnalités

* 🧼 Présentation des services de lavage
* 📱 Interface responsive
* 🎨 Design orienté utilisateur
* 🖼️ Mise en avant des images et prestations
* ℹ️ Page d’information sur le service
